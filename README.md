# Vision-Proto-v0

A lightweight static prototype inspired by **Vision** from the Avengers universe.

## Prototype

Open `/home/runner/work/Vision-Proto-v0/Vision-Proto-v0/index.html` in a browser to view:
- Vision-themed hero section
- Core capability cards
- Mission status panel

## Python Vision Assistant

This repository also includes a simple Vision-inspired Python assistant:
- Voice greeting and spoken responses
- Webcam-based face detection
- Live face counter overlay

### Requirements

- Python 3.9+
- `opencv-python`
- `pyttsx3`

Install dependencies:

```bash
pip install opencv-python pyttsx3
```

Run the assistant:

```bash
python /home/runner/work/Vision-Proto-v0/Vision-Proto-v0/vision_assistant.py
```

Press `q` in the camera window to close.
